# Chat Application

## Overview

The Chat Application is a Python-based client-server messaging system that enables users to communicate in real time through chat rooms. It provides secure user authentication, persistent message storage and a graphical interface for seamless communication.

## Objective

The objective of this project is to develop a real-time chat application using socket programming that supports secure messaging, user authentication and room-based communication.

## Features

- Client-server architecture
- User registration and login
- Secure password hashing
- Multiple chat rooms
- Real-time messaging
- SQLite database for user accounts and messages
- Message history
- Emoji support
- Graphical user interface
- Multi-client support using threading
- Input validation and error handling

## Technologies Used

- Python
- Socket Programming
- Threading
- SQLite
- Tkinter
- JSON
- Hashlib

## Installation

No additional libraries are required.

## Usage

Run the application:

```bash
python main.py
```

Choose one of the following options:

- Start Server
- Start Client

Launch the server first, then start one or more clients. Register an account, log in and join or create a chat room to begin messaging.
