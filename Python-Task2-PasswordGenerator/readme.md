# Password Generator

## Overview

The Password Generator is a Python application that generates secure and customizable passwords. It supports both Command Line Interface (CLI) and Graphical User Interface (GUI) modes, allowing users to create strong passwords based on selected character types and length.

## Objective

The objective of this project is to develop a secure password generation tool that helps users create strong and reliable passwords with customizable options.

## Features

- Supports both CLI and GUI modes
- Generates secure random passwords
- Custom password length selection
- Supports uppercase, lowercase, numbers and symbols
- Option to exclude ambiguous characters
- Password strength indicator
- Password history
- Copy password to clipboard
- Validates user input

## Technologies Used

- Python
- Tkinter
- ttk
- random
- secrets
- string
- pyperclip

## Installation

Install the required dependency:

```bash
pip install pyperclip
```

## Usage

Run the application:

```bash
python main.py
```

Choose one of the following modes:

- CLI (Command Line Interface)
- GUI (Graphical User Interface)

Select the password length and character types to generate a secure password.
